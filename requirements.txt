#  The `mcp<2` pin is NOT optional.

#  `mcp.server.fastmcp` module. Every server in this repo uses
#  `from mcp.server.fastmcp import FastMCP`, i.e. the v1 API. On mcp 2.x each

#      ModuleNotFoundError: No module named 'mcp.server.fastmcp'

#  https://py.sdk.modelcontextprotocol.io/v2/migration/
