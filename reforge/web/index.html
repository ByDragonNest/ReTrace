How ReTrace works

ReTrace is a local binary-audit workspace: it combines deterministic static analysis, MCP tools and an optional LLM agent.

1

Project

Create or open a project. Each project stores chat, findings, evidence, tool logs and LLM usage estimates in SQLite, with a compatibility JSON mirror.

2

Target

Set the binary in the Projects section. Offline static analysis starts immediately: hashes, strings, imports, hardening, attack surface and first findings.

3

Optional AI

With Anthropic or a local model you can ask for deeper analysis. The agent uses the available tools, updates findings and shows its operational reasoning in the chat.

4

MCP tools

MCP servers expose functions like decompilation, xrefs, advanced strings, mitigation audits, diffing and debugging. You can enable or disable them from Servers & tools.

5

Findings & evidence

Findings have a status, severity, CWE, location and references to stable evidence. The Evidence section keeps the technical proof so it's never lost in the chat.

6

Report

The Report button generates an exportable draft. Pre-export warnings help distinguish confirmed findings from hypotheses and weak observations.

Claude API cost estimate

When the provider is Anthropic, the API returns the tokens used by the request. ReTrace stores them and shows an estimate in the top-right corner and as a chat note after each call.

The estimate is calculated locally from the configured model's per-million-token price list. It does not include any discounts, marketplace pricing, enterprise plans, or server-side tool costs not used by ReTrace.
