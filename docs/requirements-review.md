# Requirements review — ReTrace against the brief

Reviewed 2026-10-13 against the brief that opened this work ("Prompt master — trasformazione di
ReTrace"), section by section. Every status below is backed by a file, a test or a measurement
named next to it; a status with nothing next to it is a judgement and is labelled as one.

**Scope decision in force:** ReTrace is a tool for **a single analyst and small teams**
(decided 2026-10-13, [ROADMAP → Out of scope](ROADMAP.md#out-of-scope)). Items the brief asked
for at enterprise scale are marked **cut**, not met, and the reason is recorded there.
**Language decision in force:** the product is English-only; the brief's "localizzazione
italiana e inglese" is the one §13 item overruled by the product owner.

Legend: ✅ met and verified · ◐ partly met (what is missing is stated) · ❌ not met · ✂ cut by
product decision · — not verifiable here (needs something outside this machine)

Gates on this revision: **839 tests pass, 2 skipped** · ruff (E9/F821/F822) clean · **mypy
clean over the whole package (77 files)** · benchmark precision 1.000 / recall 1.000, no
regression vs `benchmarks/baseline.json`, reproducible across 3 runs · release artifact (wheel +
sdist) verified free of state and secrets · SPA loads from a clean origin with no console error.

## Defects found during this review (all fixed)

1. **The SPA did not load at all.** Two `Object.assign(I18N.it, …)` blocks survived the removal
   of the Italian catalogue and threw `TypeError` at script load. Every static test passed. Found
   by opening the page.
2. **The project list never rendered.** `GET /api/projects` answers `{"projects": [...]}`; four
   SPA call sites expected a bare array → `list.map is not a function` on first load.
3. **A rejected finding reached the model as a Python dict with `is_error=False`** —
   `_handle_finding` returned a dict on one branch and a string on the other.
4. **`report_pt._slugify` imported a function that did not exist** and silently fell back; the
   HTML/PDF table of contents could not have worked. One `slugify` now, and headings carry ids.
5. **75 type errors outside the old mypy scope**, including `.group()` on a possibly-None match,
   `None` returned where `str` was declared, and handlers dereferencing the MCP host before
   start-up (now a 503 instead of a stack trace).
6. **`docs/installation.md` documented `retrace config set`, which did not exist.** Implemented
   (`reforge/__main__.py`, `tests/test_cli.py`) rather than un-documented.
7. **The product was not English-only.** ~300 Italian literals in the MCP servers, the SPA's
   playbook/strings/imports copy tables, the graph-diff highlights, five backend modules, seven
   playbook prompts, and a test that asserted on an Italian sentence. All translated; the guard
   now covers everything that ships.
8. **LLM calls had no explicit timeout** — the SDK default (10 min) applied. `llm_timeout_s`
   and `llm_max_retries` are settings now and both clients receive them.

   and expiry (an `ACCEPTED_RISK` status). This is the largest functional gap for a small team.

   procurement asks for first.

4. §9.3 — `evals/`: score the *model* on tool selection, policy adherence, injection resistance
   and invented evidence. The deterministic halves are tested; the model is not.
5. §14 — a browser-level end-to-end test. Two regressions this review found would have been caught.
6. §8 — per-CWE breakdown, per-phase timing, the two call-site/source→sink percentages.
7. §14 — decompose `server.py`, `app.js`, `agent.py`; property/fuzz tests for the PE/ELF/XML

8. §9.2 — circuit breaker and provider fallback at the LLM layer.
9. §6.3 — channel authentication for remote MCP servers.
